## <img src="https://api.iconify.design/mdi/information-outline.svg?color=%236366F1" width="24" style="vertical-align:middle"/> About the Project

**Skoolution** is a mobile app built to help Moroccan students figure out where they really stand in each school subject — Math, Physics/Chemistry (PC), Life & Earth Sciences (SVT), Arabic, French, and more — and then follow a clear path to improve.

The idea is simple:

1. The student takes a short diagnostic **test** in a given subject.
2. The app evaluates their current **level** (niveau) in that subject.
3. Based on the result, the app will provide a personalized **roadmap** to follow so the student can progressively grow their level.

This project started from a complete **Figma UI design**, which is being turned into a real, working mobile application using **Flutter** and **GetX**.

> ⚠️ Skoolution is currently in active development and is **not yet published on the Google Play Store**.

## <img src="https://api.iconify.design/mdi/sitemap.svg?color=%236366F1" width="24" style="vertical-align:middle"/> Architecture

Skoolution follows a modular Flutter architecture with a clear separation of concerns:

1. **Flutter UI** — Screens and widgets built directly from the Figma design: onboarding, subject selection, tests, results, and roadmap views.
2. **GetX Controllers** — Manage test logic, level calculation, reactive state, and navigation between screens.
3. **Dependency Injection (GetX)** — Manages controllers and services throughout the app lifecycle.
4. **Data Layer** — Stores subjects, test questions, student results, and generated roadmaps.

This structure keeps the UI fully decoupled from the test logic and level-evaluation engine, making it easy to add new subjects and tests over time.
